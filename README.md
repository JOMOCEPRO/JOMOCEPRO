### Perfil Técnico
Desarrollo soluciones de software autónomas, rápidas y sin dependencia de suscripciones en la nube (*Local-First*), orientadas a la automatización operativa de comercios, gestión de inventarios, generación documental e integración de flujos con inteligencia artificial.

* **Lenguajes y Backend:** Python (Streamlit, Flask, Tkinter, FastMCP), SQLite, MySQL, PowerShell.
* **Sistemas de Escritorio y Automatización:** Empaquetado portable en Windows (`PyInstaller`), integración en System Tray (`pystray`), impresión térmica directa (`win32print` / `ReportLab`), automatización web (`Playwright`).
* **Inteligencia Artificial y Orquestación:** Servidores MCP (*Model Context Protocol*), flujos multi-agente con OpenClaw, Ollama y NVIDIA NIM.
* **Infraestructura y Hardware:** Diagnóstico de redes CAN, sistemas CCTV y mantenimiento de firmware a bajo nivel.
